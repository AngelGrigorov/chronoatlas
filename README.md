# Атлас на историята

Карта на света с таймлайн отдолу. Колелцето мести времето, а картата
показва кой къде е бил, какво се е случило и накъде са вървели походите.
Започва от 10 000 г. пр.Хр. и стига до днес.

```
npm install
npm run serve     # http://localhost:8642
```

## Какво има

- **Граници** от [historical-basemaps](https://github.com/aourednik/historical-basemaps)
  (A. Ourednik, GPL-3.0): 53 моментни снимки на света. Между две снимки
  картата прескача, и това е нарочно: горе вляво пише към коя година са
  границите, а на таймлайна снимките са златни ромбчета. Приблизителните
  граници (`BORDERPRECISION` 1) са размити, а точните са с ясна линия.
- **Ореоли** за култури без ясни граници — Шумер, Харапа, траките, Лапита,
  викингите — светят и гаснат с времето (`data/content/cultures.json`).
- **371 подбрани събития** на български в `data/content/events-*.json`.
  Светват в годината си и избледняват. Колко дълго остават, зависи от
  мащаба на таймлайна.
- **Wikidata**: битки, обсади, договори, изригвания и земетресения. Те се
  показват при приближение, а по-известните (с повече езици) излизат
  по-рано (`data/wd-events.json`).
- **Пътища и походи**: търговските пътища са пунктир, докато са активни.
  Походите се рисуват точка по точка с годините си и имат светеща глава.
- **Градове** с имената им през вековете: Византион → Константинопол →
  Истанбул, Пулпудева → Филипопол → Пловдив.
- **Епохи** в осем пътечки: свят, Европа, Близкия изток, Египет, Китай,
  Индия, Америките и България.
- **„Едновременно“** — панел с това какво има по света в избраната година,
  по региони.
- **Търсене** по всичко изброено. Избраният резултат премества и годината, и картата.
- **▶** пуска историята като филм. Годината е в адреса (`#y=-490`), така че
  всяко място може да се прати като линк.

## Управление

| | |
|---|---|
| колелце върху таймлайна | време напред/назад |
| Ctrl + колелце, щипка | мащаб на таймлайна |
| влачене на таймлайна | време, с инерция |
| клик / двоен клик върху епоха | скок / побиране на епохата |
| ← → (Shift за повече) | време |
| интервал | ▶ / пауза |
| `/` | търсене |
| Esc | затваря картичката |

## Как е направено

Няма build стъпка. `public/` е готовият сайт: един HTML, CSS, пет ES модула
и MapLibre GL 6 (вендорнат в `public/vendor`). Сервира се от всеки статичен
сървър.

- `js/map.js` — картата, слоевете, двата буфера за границите с преливане и
  канвасът за етикети. Етикетите са на канвас, а не символи на MapLibre,
  защото MapLibre иска сървър за глифове на кирилица. Канвасът ги рисува
  с Cormorant Garamond на два слоя: държави отдолу, градове и събития отгоре.
- Времето стига до слоевете през `global-state` на MapLibre (`year`, `win`).
  Непрозрачността на събитията, походите и културите се смята в GPU израза,
  така че при въртене на годината не се презарежда никакъв източник.
- `js/timeline.js` — таймлайнът е канвас с фиксиран курсор в средата.
- `js/panel.js` — панелът и картичката. Картичката тегли резюме и снимка от
  Уикипедия на живо (първо българската). Без мрежа просто ги няма.
- Годините са исторически: −490 е 490 г. пр.Хр., нулева няма. WDQS дава
  астрономически години, затова при импорта от тях се вади 1.

## Данните

Суровите набори не са в git (`.cache/`). Ето как се пресъздават:

```
# historical-basemaps → .cache/hb/*.geojson и index.json
# Natural Earth 1:50m → .cache/ne/ (ne_50m_land, ocean, lakes, rivers_lake_centerlines, NE2_50M_SR_W)
npm run data                    # границите, етикетите, entities.json, основата
python tools/build-relief.py    # релефът на плочки z0–5 (6.9 MB webp)
node tools/fetch-wikidata.js    # ~25 мин, продължава след прекъсване
node tools/build-wd.js          # → public/data/wd-events.json
```

Имената на 3000-те държави и народи са преведени на ръка в
`tools/names-bg/*.json`. Ако нова версия на historical-basemaps донесе нови
имена, `npm run data` изписва колко са без превод и ги записва в
`.cache/missing-names.txt`.

## Проверка

```
npm test          # годините, регионите, рязането на пътищата на ±180°
npm run serve
npm run smoke     # headless Chrome: колелце, мащаб, влачене, търсене, клик, ▶, телефон
```

Снимките отиват в `.cache/shots/`.
